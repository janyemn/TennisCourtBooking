# 每人一台电脑的本地版本

当前可用：南山文体通市民账号首次绑定、本人会话同步、已接入场馆的预约。
尚未完成：师生预约、微信一键授权、自动重新登录微信。

1. Windows 电脑安装 Node.js 20 或更高版本。解压后双击 start-app.cmd。
2. 可先用本人 HAR 在网页导入，系统会验证实名信息并绑定本人参与人；不继承分发者账号。
3. 免 HAR 同步还需 Python 3.11 或更新版本，在项目目录执行：

   ```powershell
   python -m venv .local/sync-venv
   .local/sync-venv/Scripts/python.exe -m pip install mitmproxy
   ```

4. 启动 start-session-sync.cmd；使用 Clash 时可用 start-session-sync-clash.cmd（当前默认上游端口17897，需与你的实际端口一致）。
5. 首次代理配置使用 tools/configure-session-sync.ps1；它会备份系统代理并安装本机生成的代理证书。先阅读脚本，恢复时使用 -Restore。不要复制其他人的证书或 .local。
6. 网页开启同步后，在电脑微信进入南山文体通，完成正常登录并打开“我的”。网页仅在平台验证成功后绑定账号。只是保持页面打开不保证产生新的登录请求。

一个本地副本绑定一个市民账号，已有账号不能被他人的会话覆盖。切勿共享正在运行的本机服务；本版本不是多人在线网站。

师生 HAR 分析：2026-09-16-222400.har 包含 yktline.utsz.edu.cn 到 yktdt.utsz.edu.cn 的微信授权跳转、校园登录页面和验证码接口。其他五份没有提供师生成功登录或预约链路。没有取得师生账号、密码或成功会话，不能用这些记录证明师生预约已接入。下一步需要实际师生在官方入口完成登录、查看网球场次和预约确认的记录；密码无需发到聊天。

自己的微信网站登录即使接入，也只证明用户登录自己的应用，不会自动取得南山文体通或校园系统的预约会话。当前没有这些平台授予本应用的登录回调或账号授权接口，因此不提供伪装的一键授权按钮。
